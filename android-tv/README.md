# MUNAISZN PLAY — Android TV

Android TV companion app for MUNAISZN PLAY.

This folder contains the Android TV app project. The existing website remains in the repository root and continues to deploy through GitHub Pages.

Target: Android 12 TV devices.

The app will use the hosted MUNAISZN PLAY website and provide TV remote navigation, landscape layout, and Android TV launcher support.

Playback availability depends on the external provider and device compatibility. This project does not host or distribute movie files.
